# LESSONS LEARNED (SỔ TAY KINH NGHIỆM DỰ ÁN FAT)

- **Windows PowerShell Execution Policy & Node Tooling:** Khi chạy lệnh `npm` hoặc `npx` trên môi trường PowerShell Windows có execution policy chặn script (`npm.ps1`), bắt buộc sử dụng `npm.cmd` và `npx.cmd` để chạy lệnh thành công và ổn định mà không bị lỗi `PSSecurityException`.
- **Global Workflows & 2-Way Registry Sync:** Khi bổ sung lệnh Global mới (`/g-*`), bắt buộc phải đăng ký 2 chiều vào `AGENT_ARCHITECTURE.md` (§2 danh sách lệnh & §5 bảng quyết định) và cập nhật `g-help.md` để luôn thỏa mãn bài kiểm tra toàn vẹn Bước 3b của `/g-health`.
- **0-Token Context Monitoring & Local Extensions:** Không dùng LLM prompt để tự đo context window (tránh hiệu ứng Observer Effect làm phình token); giải pháp chuẩn native là xây dựng Local Extension VS Code (`~/.antigravity-ide/extensions/`) đọc session log trực tiếp từ disk và hiển thị qua StatusBarItem.
- **Public Extension Decoupling:** Khi đóng gói công cụ hoặc extension phát hành công khai (Marketplace/Open VSX), bắt buộc phải tách rời (decouple) các lệnh nội bộ cá nhân (như `/g-compact`) thành các chỉ dẫn ngữ cảnh phổ quát (ví dụ: "Prompt AI to summarize state and start a new session") để bất kỳ người dùng nào cũng hiểu và áp dụng được.
- **Marketplace Icon Design:** Icon cho các tiện ích developer tooling trên Marketplace cần theo phong cách phẳng (Flat design), tối giản hiện đại (Swiss design style) với biểu tượng đo tiến độ vòng cung (circular progress gauge), màu gradient tinh tế trên nền squircle tối màu để tạo cảm giác chuyên nghiệp, không dùng hiệu ứng 3D neon quá rườm rà.
- **Anti Box-in-Box UI & Fresh Jade Heritage Design:** Trong thiết kế giao diện phả hệ/văn hóa số, tuyệt đối tránh lối mòn "lồng hộp" (box-in-box: thẻ bọc khối icon vuông bọc viên thuốc tag) và các gam màu nâu đất/hổ phách u tối dễ gây cảm giác đình chùa cũ kỹ; thay vào đó, áp dụng phong cách "Modern Vietnamese Heritage": nền trắng sứ với quầng sáng ngọc bích (Jade Emerald `#059669`), đường kẻ hairline siêu mảnh 1px (`border-slate-200/60`), icon nổi tự do và typography Be Vietnam Pro phân cấp rõ ràng để tạo cảm giác trang trọng, thanh thoát và tràn đầy sinh khí.
- **Offline Resilient Dev Auth & Server-First State:** Khi môi trường mạng chặn Google OAuth / external endpoints, không để client-side gọi `supabase.auth.getUser()` vô hạn định (gây treo UI ở trạng thái Loading). Giải pháp chuẩn: (1) Fast-check sự tồn tại của auth cookie trước khi gọi network; (2) Thiết lập Server Component (`Navbar.tsx`) lấy session trên server và truyền `initialUser`/`initialProfile` xuống client để render tức thì 0ms; (3) Dùng link trực tiếp `/api/auth/dev-login?action=login` set cookie dev (`httpOnly: false`) để bypass hoàn toàn OAuth mạng ngoài mà không cần đợi client JS hydration.
