# LỆNH: /doc-qa

**Mục tiêu:** Chuẩn hoá quy trình đảm bảo chất lượng (QA).

1. Đọc lướt qua toàn bộ ngữ cảnh dự án (01 đến 06).
2. Đọc file `docs/templates/07_template_Kiem-thu_Test-QA-Strategy.md`.
3. Thiết lập các tiêu chuẩn về Unit Test, Integration Test, E2E Test cho dự án này.
4. Tạo file `docs/07_Test-QA-Strategy.md`.
5. Thông báo cho User biết đã xong. Khuyên User chạy tiếp lệnh `/doc-deploy`.
