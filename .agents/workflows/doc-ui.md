**Mục tiêu:** Cụ thể hoá luồng trải nghiệm người dùng.

1. Bắt buộc phải đọc file `docs/01_Architecture-Blueprint.md` và `docs/02_Project-Glossary.md`. (Báo lỗi nếu chưa có).

5. Thông báo cho User biết đã xong. Khuyên User chạy tiếp lệnh `/doc-tech`.
