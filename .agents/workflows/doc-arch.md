# LỆNH: /doc-arch

**Mục tiêu:** Chuyển hoá ý tưởng thành Kiến trúc & Luồng nghiệp vụ chính thức.

1. Đọc lại ngữ cảnh từ buổi thảo luận `/idea-init` vừa rồi. (Nếu User chưa có ý tưởng rõ ràng, khuyên họ chạy `/idea-init` trước).
2. Hãy đọc `docs/templates/01_template_Ban-ve-Kien-truc_Architecture-Blueprint.md`.
3. Trích xuất thông tin và tạo file `docs/01_Architecture-Blueprint.md` tuân thủ đúng định dạng của template.
4. Thông báo cho User biết đã xong. Khuyên User chạy tiếp lệnh `/doc-glossary`.
