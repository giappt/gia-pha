# LỆNH: /doc-glossary

**Mục tiêu:** Xây dựng bộ từ vựng chuẩn cho dự án.

1. Bắt buộc phải đọc file `docs/01_Architecture-Blueprint.md` để lấy ngữ cảnh. (Nếu chưa có file này, yêu cầu User chạy `/doc-arch` trước).
2. Đọc file `docs/templates/02_template_Chuan-hoa-Tu-vung_Project-Glossary.md`.
3. Nhặt ra tất cả các "danh từ/khái niệm" quan trọng xuất hiện trong File 01.
4. Tạo file `docs/02_Project-Glossary.md` và trình bày chúng dưới dạng từ điển/bảng tra cứu theo template.
5. Thông báo cho User biết đã xong. Khuyên User chạy tiếp lệnh `/doc-db`.
