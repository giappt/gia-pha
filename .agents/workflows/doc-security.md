# LỆNH: /doc-security

**Mục tiêu:** Đảm bảo dự án an toàn và lường trước các rủi ro bảo mật.

1. Bắt buộc đọc `docs/01`, `docs/03`, và đặc biệt là `docs/05` để biết dự án đang dùng Tech Stack nào.
2. Đọc file `docs/templates/06_template_Bao-mat_Security-Threat-Model.md`.
3. Đóng vai trò là Kỹ sư Bảo mật, đánh giá rủi ro (Injection, XSS, CSRF, DDoS, Leak data...) dựa trên Tech Stack hiện tại.
4. Tạo file `docs/06_Security-Threat-Model.md`.
5. Đề xuất các biện pháp phòng ngừa vào tài liệu.
6. Thông báo cho User biết đã xong. Khuyên User chạy tiếp lệnh `/doc-qa`.
