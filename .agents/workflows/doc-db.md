# LỆNH: /doc-db

**Mục tiêu:** Thiết kế toàn bộ cơ sở dữ liệu dựa trên kiến trúc và từ vựng đã chốt.

1. Bắt buộc phải đọc file `docs/01_Architecture-Blueprint.md` và `docs/02_Project-Glossary.md`. (Báo lỗi nếu chưa có).
2. Đọc file `docs/templates/03_template_Thiet-ke-Du-lieu_DB-Schema.md`.
3. Phân tích các Entities (Thực thể) và Mối quan hệ (Relationships) cần thiết.
4. Tạo file `docs/03_DB-Schema.md` với định nghĩa chi tiết các bảng/collection. Tuyệt đối sử dụng đúng từ vựng đã chốt trong File 02 (không bịa từ khác).
5. Thông báo cho User biết đã xong. Hỏi User xem họ có muốn bắt đầu Phase 2 bằng lệnh `/doc-ui` không.
