# LỆNH: /doc-tech

**Mục tiêu:** Chốt giải pháp công nghệ kỹ thuật dựa trên các yêu cầu từ file 01 đến 04.

1. Bắt buộc phải rà soát qua các file: `docs/01_...`, `docs/02_...`, `docs/03_...`, `docs/04_...`.
2. Đọc file `docs/templates/05_template_Thiet-ke-Ky-thuat_Technical-Blueprint.md`.
3. Phân tích để đưa ra lựa chọn: Ngôn ngữ lập trình, Framework Frontend, Framework Backend, Database (đã có ở 03), Các thư viện 3rd-party.
4. Xác định các API cơ bản (API Contract).
5. Xác định các Milestones (Các cột mốc phát triển). (Ví dụ: Milestone 1: Auth, Milestone 2: CRUD...).
6. Tạo file `docs/05_Technical-Blueprint.md`.
7. Dừng lại, xin ý kiến User về Tech Stack. Khuyên User chạy tiếp lệnh `/doc-security`.
